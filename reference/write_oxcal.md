# Write CQL to a file

Writes a CQL script (from [`cql()`](cql.md)) to an .oxcal file, for
input to OxCal.

## Usage

``` r
write_oxcal(cql, file)
```

## Arguments

- cql:

  A `cql` object. See [`cql()`](cql.md).

- file:

  Path to a file.

## Value

Returns `cql` invisibly.
