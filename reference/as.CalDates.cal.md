# Convert cal objects to a rcarbon CalDates object

Convert cal objects to a rcarbon CalDates object

## Usage

``` r
as.CalDates.cal(x)
```

## Arguments

- x:

  A list of `cal` objects.

## Value

A `CalDates` object. See
[`rcarbon::calibrate()`](https://rdrr.io/pkg/rcarbon/man/calibrate.html)
for details.
