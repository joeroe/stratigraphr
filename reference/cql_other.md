# Other CQL functions (unimplemented)

These CQL commands are not yet implemented in stratigraphr and only
included here for reference. Unimplemented commands can be included
manually using
[`cql()`](https://stratigraphr.joeroe.io/reference/cql.md) (see
examples), but if you need one for an analysis please file a bug report!
